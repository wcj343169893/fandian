基于智能点餐原型设计的微信小程序界面，主色森林绿，底部 Tab：首页 / 点餐 / 订单 / 我的。右侧为可交互原型。

设计说明

  • 首页头图为可配置图片轮播，图片缺失时回退为品牌绿渐变
  • 导航栏悬浮时，状态栏与导航栏同为实底
  • 仅当门店数 > 1 时显示「切换门店 / 附近门店」入口
  • 扫桌码进入：小程序码带 store + table 参数，自动入座；直接打开（无参数）：首页弹出扫码引导，点餐页保留「未入座」提示，结算前必须绑定桌号（打包除外）
  • 真机扫码调用 wx.scanCode；扫不了时可手动输入桌码下方的桌号
  • AI 配一桌：改人数 / 预算 / 策略 / 偏好只改草稿，配菜区盖蒙板，确认后才重新配菜，避免拖动预算时菜单反复跳动
